Publish safely

Usa Published para mostrar u ocultar. El borrado y el cambio de nombre están bloqueados en el panel. Para retirar algo, apaga Published.

04

Security

El editor requiere autenticación con GitHub. Esta página no contiene contraseñas, tokens ni secretos.

First access: inicia sesión en Pages CMS con GitHub, instala su GitHub App únicamente en el repositorio vdb-chmp/e-deboer-web y ábrelo. La configuración .pages.yml ya está preparada. Un pequeño proceso automático reconstruye el índice público después de cada cambio.

Cuando el dominio propio esté detrás de Cloudflare, protege además la ruta /studio/* con Cloudflare Access y una regla Allow limitada a tu identidad.

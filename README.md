# E. DE BOER — portfolio website

Static, responsive portfolio website prepared for GitHub Pages.

## Pages
- `index.html` — Home
- `work.html` — Work / personal studies
- `about.html` — About
- `contact.html` — Contact

## Before public launch
1. Replace the temporary/generated study imagery with final portfolio images as they become available.
2. Add the real email address in `contact.html` after the domain/email setup is complete.
3. Connect the chosen custom domain (`e-deboer.com`) in GitHub Pages or Cloudflare.
4. When/if `edeboer.com` is acquired, set it as the canonical domain and 301-redirect the old domain.

## Hosting
No build system is required. The folder can be published directly with GitHub Pages.
